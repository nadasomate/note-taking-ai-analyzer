# Note-Taking AI Analyzer

This project is an interactive **Streamlit web application** designed to analyze and compare AI note-taking applications available on the Google Play Store.

It allows users to explore app data, visualize statistics, and perform sentiment analysis on user reviews using AI models.

## Features

-  Search for note-taking AI apps from Google Play Store
-  Display and filter app results (rating, installs, pricing, genre)
-  Visualize app statistics:
  - Rating distribution
  - Free vs Paid apps
  - Genre distribution
-  Sentiment analysis on user reviews (Positive / Negative)
-  Interactive UI built with Streamlit

## Technologies

- Python
- Streamlit
- Pandas
- Matplotlib
- Google Play Scraper
- Transformers (NLP)
